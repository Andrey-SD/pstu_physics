## 📚 PSTU Physics — Віртуальні лабораторні роботи

Колекція навчальних **віртуальних лабораторних робіт з фізики** у форматі веб-застосунків.  
Проєкт зібраний як **єдиний каталог**, де кожна лабораторна робота відкривається як окрема сторінка.

✅ Єдина стартова сторінка-каталог зі списком ЛР
